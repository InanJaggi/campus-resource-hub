# Product Management Context Materials

This folder contains Product Management artifacts that provide context for AI tools and development decisions.

## Contents

- **PRD.txt**: Product Requirements Document (PRD) for Campus Resource Hub v1.0
  - Contains objective, stakeholders, non-goals, core features, and success metrics
  - Used by the AI chatbot for context grounding (referenced in `src/controllers/chatbot.py`)
  - Provides project vision and requirements alignment

- **AiDD_PRD.docx**: Original PRD document in Word format

## Usage

The PRD content is integrated into the AI chatbot's context system to ensure responses align with project objectives and stakeholder needs. This demonstrates context grounding as required by Section 9 of the AiDD 2025 project requirements.

## Context for AI Tools

These materials help AI tools (Cursor, Copilot, etc.) understand:
- Project objectives and success criteria
- Stakeholder needs and priorities
- Feature requirements and constraints
- Business context and goals
