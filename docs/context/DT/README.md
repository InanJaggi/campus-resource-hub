# Design Thinking Context Materials

This folder contains Design Thinking artifacts that provide context for AI tools and development decisions.

## Contents

- **WireframeMain.png**: Main/homepage wireframe showing layout and navigation structure
- **WireframeDetails.png**: Resource detail page wireframe showing booking flow and information display
- **WireframeDashboard.png**: User dashboard wireframe showing bookings, resources, and messages
- **WireframeLogs.png**: Admin logs and booking management wireframe

## Usage

These wireframes were used during the design phase to plan the user interface and user experience. They provide visual context for AI tools to understand the intended layout and user flow.

## Context for AI Tools

These materials help AI tools (Cursor, Copilot, etc.) understand:
- User interface layout and structure
- User flow and navigation patterns
- Visual design intentions
- User experience considerations
